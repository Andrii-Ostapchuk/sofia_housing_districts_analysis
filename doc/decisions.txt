As the main point of analysis official 24 administrative districts of Sofia Municipality.

Listing location names are inconsistent with the official distric and neighborhoos names. Not all location names are
available in the file "districts". Even the names that are included make mapping unreliable because of granularity inconsistency.
(e.g. "Ovcha kupel" in one table and "Ovcha kupel 1", "Ovcha kupel 2" in another).
To facilitate the research it was concluded to generalize and include as many district names as the location actually overlaps. 
The overlap dictionary was generated by AI and then manually verified.

Bridge table files were created for rental and sales listings separately to facilitate further quering. 

Each district accessibility topic will be contained in a separate file with all relevant data.
